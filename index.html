The repair build, billed like a show and worked like a rail. Every line here is tied off: what the extension does, how a line gets spoken, what was broken, and what was re-tied.

Station I

The job itself

This repository is the fix build of TTSSorcery, a SillyTavern extension in index.js, style.css, and manifest.json, plus one extra file the other build does not carry: model_instructions.md, a standalone copy of the marker instructions template. It has no connection to the speech feature SillyTavern ships with, and chat completions are the only generation mode it supports.

Station II

How a line gets spoken: a lift in four moves

A prompt is injected so the model writes markers into its streamed reply. The template in model_instructions.md defines three kinds: a narrator marker naming voice file and emotion values, an action marker for narration without emotion values, and a character marker naming the character, the voice file, and the values, with shorter repeat forms allowed after a first full appearance. Unknown characters fall back to the Narrator with default.mp3, and a missing voice file falls back to default.mp3.

The extension parses the markers, posts each segment to Zyphra at https://api.zyphra.com/v1/audio/text-to-speech, and plays the returned audio in order while the reply is still streaming. Emotion values run from e1 to e8, happiness at the head of the list and neutral at its foot, with sadness, disgust, fear, surprise, anger, and other in between, each scored from 0.0 to 1.0.

Station III

The repair ledger

The manifest declared style.css while no stylesheet shipped, so the file failed to load.The stylesheet is present now.
Preset handlers reached for a presets field and panel controls that a fresh install did not have, and threw.A Default preset is now seeded and the settings panel carries list, new, delete, export, and import controls for presets.
A soft queue reset at stream start read a flag that was never defined, so the reset died inside the host event dispatch every time a stream began.That read is fixed.
Event handlers for the prompt ready and stream token events were registered twice in earlier revisions, risking instructions injected twice.They are registered once.
The Zyphra call once ran over plain HTTP, which would have sent the API key unencrypted.It runs over HTTPS now.
Station IV

Running it, and the limits that remain

Setup: a Zyphra key from the free tier at 100 minutes a month placed in the extension settings, at least one Narrator voice sample uploaded, character voices added, the extension enabled, and auto generation only while streaming is on, with manual generation from the wand icon. It cannot run outside SillyTavern, since index.js imports host modules by relative path.

The bug warning stays: the extension carries many bugs, leans heavily on a capable model placing markers correctly, and was tested only against a short list of Claude models and Gemini Pro.

Tests: a Node suite under test/ that loads index.js against a stub host tree, run on Node 20 or newer with node --test test/ttssorcery.test.mjs test/presets-import.test.mjs, covering preset seeding and panel actions, instruction injection, stream resets, parsing and segmentation, Zyphra request bodies, voice fallback, and queue drain.

The flat has reached its mark and is tied off, the border hangs straight, and the spoken reply finished with every voice back in its place.
